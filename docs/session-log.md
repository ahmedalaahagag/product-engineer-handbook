# Session Log

## Purpose

A session log is the inbox for long-running product work.

It carries context across agents, models, and days.

## When To Use It

Use a session log for:

- multi-ticket work
- cross-repo work
- cross-lane work
- long-running initiatives
- important status changes

Skip it for tiny single-file edits.

## Entry Format

```text
YYYY-MM-DD · <lane>/<session-type> · <summary> · <ref>
```

## Benefit

The next session does not need to guess what happened.

The log reduces repeated discovery and prevents lost context.
