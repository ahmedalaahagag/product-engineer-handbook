# Human Review and Manual Merge

## Rule

AI can generate work.

AI can review work.

AI can suggest changes.

AI cannot approve production changes.

## Human Review Checks

Before merge, the engineer checks:

- product intent
- architecture fit
- code quality
- security risk
- regression risk
- whether the change matches the ticket

## Manual Merge

Every merge should be intentional.

Do not auto-merge generated changes by default.

The merge is the moment where ownership is accepted.

## Benefit

This keeps AI as leverage without turning it into an unaccountable production actor.
