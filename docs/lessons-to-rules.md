# Lessons To Rules

## Problem

Teams repeat the same AI workflow mistakes because lessons stay buried in chats.

## Rule

When a session discovers a durable lesson, record it.

If the lesson generalizes, promote it into a standing rule.

## Lesson Format

- What happened
- What was learned
- Where it happened
- What rule should change

## Promotion Path

```text
Incident
-> Lesson learned
-> Standing rule
-> Agent instruction
-> Future behavior
```

## Benefit

The workflow improves over time instead of relying on memory.
