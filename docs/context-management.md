# Context Management

## Problem

Long AI sessions become expensive, noisy, and hard to control.

## Rule

Make sessions disposable.

Make knowledge persistent.

## Store durable context in files

- AGENTS.md
- plans
- specifications
- tickets
- handovers
- lessons learned
- session logs

## Benefits

- lower token usage
- cheaper execution sessions
- cleaner handoffs
- easier model switching
- less dependence on one chat history
