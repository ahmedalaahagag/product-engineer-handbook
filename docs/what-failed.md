# What Failed

These are the patterns that slowed delivery or created risk.

## Endless sessions

Large contexts accumulate noise.

They become slower, more expensive, and harder to steer.

## Huge tickets

Large requests create ambiguity.

Ambiguous tickets produce broad implementations that are difficult to review.

## Premature workflow optimization

Improving the workflow before proving a bottleneck slows delivery.

The workflow exists to ship product.

If the workflow becomes the product, simplify.

## Blind trust in AI output

Generated code still requires verification.

AI can be confidently wrong.

## Chasing every new model

Tool switching often creates more overhead than value.

Change models when there is a clear role or bottleneck, not because a new model is available.

## Assuming memory exists

Important information should be documented explicitly.

If the next session needs it, put it in an artifact.
