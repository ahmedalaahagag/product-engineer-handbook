# AGENTS.md

## Purpose

This meta repository is used for planning, coordination, specifications, tickets, handovers, verification notes, and durable project memory.

Do not implement product code here.

## Working Rules

- Start by identifying the lane.
- Brainstorm before planning when the goal is unclear.
- Write plans before tickets.
- Write specs before execution handovers.
- Keep tickets small and verifiable.
- Human review is required before execution and merge.
- Archive completed or stale context.

## Lanes

- product: product value, scope, tradeoffs, release shape
- coding: implementation, tests, maintainability, verification
- ui-ux: flows, screens, copy, usability
- marketing: positioning, messaging, distribution
- release: rollout, checklists, risk, launch coordination

## Verification

Every execution handover should include the verification command expected to prove the work is done.
